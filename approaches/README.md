# Approaches

This folder holds community-submitted **approaches**: ideas, reformulations, partial results, heuristics, and computational experiments aimed at the problems in this catalogue.

## How it's organized

Create a subfolder named after the problem, then add your file:

```
approaches/
  004-collatz-conjecture/
    my-density-argument.md
    experiments/            (optional: code, data)
  003-twin-prime-conjecture/
    sieve-idea.md
```

## What a good approach file looks like

Follow the structure from the [issue template](../.github/ISSUE_TEMPLATE/new-approach.md):

1. **The idea** — the core insight or strategy.
2. **What I can justify** — proven/supported steps, with references.
3. **What I cannot (yet) justify** — the gaps, honestly stated. *This is the most important section.*
4. **Evidence** — small cases, computations, data.
5. **Self-critique** — where it gets stuck, and why it might not have been done before.

## Ground rules

- Clearly label **proven** vs. **conjectured** vs. **guessed**.
- Cite sources.
- It's completely fine to post an idea that doesn't work — a well-explained dead end is genuinely useful and welcome.
- Read [CONTRIBUTING.md](../CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) first.
